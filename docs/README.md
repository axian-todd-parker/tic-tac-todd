# Project Documentation

This directory is the source of truth for how work is planned, executed, and recorded in this repository.

Current documents:

- `working-agreement.md`: non-negotiable rules for how changes are made.
- `project-intent.md`: the target end-state, scope, and delivery goals.
- `action-log.md`: a running record of meaningful actions and their outcomes.
- `deployment.md`: deployment approach and commands for AWS.

Usage:

1. Review `working-agreement.md` before making changes.
2. Update `project-intent.md` if scope or exit criteria change.
3. Add to `action-log.md` whenever a material action is completed.

Current implementation commands:

- `npm run dev`: start the local Vite app.
- `npm run build`: type-check and create a production build.
- `npm run lint`: run ESLint.
- `npm run test:unit`: run unit tests for the game module.
- `npm run test:e2e`: run the Playwright browser flow.
