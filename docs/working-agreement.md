# Working Agreement

These rules apply to all future work in this repository.

1. Always reference the appropriate documentation before making changes.
2. Keep technical documentation and the human-friendly `README.md` current.
3. Always plan work before executing it.
4. Test everything. Tests must pass before moving to the next step.
5. Ask when a required answer cannot be determined confidently.

Execution guidance:

- Prefer small, verifiable changes over large batches.
- Record intent before work starts and record outcome after work completes.
- Do not leave undocumented behavior, assumptions, or scope changes behind.
